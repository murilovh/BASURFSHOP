# Plaquinha de avaliação no Google

O QR code leva direto para a tela de avaliação da loja no Google:

https://search.google.com/local/writereview?placeid=ChIJUc2QNADNJpURo3_edX4J7DU

O ID `ChIJUc2QNADNJpURo3_edX4J7DU` é o do perfil "Baboardshop - Surf concertos" no Google Maps (conferido em 05/11/2026). Para avaliar, o cliente precisa estar logado numa conta Google. Se o nome do perfil for corrigido, o link continua funcionando, porque o ID não muda.

## Arquivos

| Arquivo | Para quê |
|---|---|
| `plaquinha-A6-grafica-com-sangria.pdf` | Mandar para a gráfica. A6 (10,5 × 14,8 cm) com 3 mm de sangria (arquivo de 11,1 × 15,4 cm). |
| `plaquinha-A4-4-unidades.pdf` | Imprimir em casa: 4 plaquinhas numa folha A4, com marcas de corte. Imprimir em "tamanho real" (100%). |
| `plaquinha-A6.png` | Imagem em 300 dpi para conferir ou mandar pelo WhatsApp. |
| `fonte/` | Modelo (`build.mjs`) e o QR (`qr.svg`) usados para gerar os arquivos. |

O QR foi testado com um leitor automático, inclusive em tamanho reduzido.
